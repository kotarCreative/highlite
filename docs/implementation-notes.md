# Implementation notes

## Milestone 0: constraints and compatibility

- Highlite uses its own proposed `0.1.0` manifest. Upstream Scrawl is public at `kitlangton/scrawl` under the MIT license; its `scrawl.json` v1 schema (`src/model.rs`) and keyframe/summary processing (`src/keyframes.rs`, `src/sketch.rs`) are inspectable. The compiler's Scrawl export is a browser subset and is not advertised as compatible until a contract test against a real Scrawl build passes.
- Browser DOM APIs cannot take a faithful screenshot of arbitrary rendered page content. Frame capture will only be reported when a user-approved frame provider supplies pixels; otherwise the bundle must state that visual evidence is unavailable.
- `getDisplayMedia()` requires an explicit user gesture and browser permission. The SDK requests the current tab with Chromium's `preferCurrentTab`, `selfBrowserSurface: 'include'`, and monitor-exclusion hints, so the picker opens with this tab preselected — but browsers always require the user to confirm the share picker, and other browsers may ignore the hints. Microphone and display capture are requested sequentially and can be denied independently; both must stop cleanly. An existing microphone grant is detected through `navigator.permissions.query({ name: 'microphone' })` so its step can be skipped; browsers that reject that query fall back to showing the step.
- The manifest records an approximate `audioOffsetMs` relative to the session clock when MediaRecorder starts. Browser chunk delivery is not treated as sample-accurate timing.
- Manifest timestamps are whole milliseconds: the monotonic clock is rounded before events, keyframes and durations are recorded, matching the compiler's `u64` millisecond contract.
- Cross-origin iframe contents, closed shadow roots, browser chrome, and sensitive pixels cannot be reliably inspected or automatically redacted by this SDK.
- MediaRecorder MIME types and permission UX vary by browser. The implementation must negotiate support instead of assuming WebM everywhere.

## Progress

- **Foundation complete:** pnpm workspace, Oxc tools, Git hooks and conventional commit enforcement, common-clock timeline, deterministic summary, ESM/IIFE builds, and a fake analytics demo.
- **Browser shell in progress:** Shadow DOM setup panel plus a centered bottom session dock with icon annotation tools, mark, discard with a confirmation dialog, and a red stop action, one-at-a-time permission modals that skip steps already granted, mic recording, current-tab display-frame provider, click/scroll/route events, privacy-aware DOM target metadata, annotations, cancellation/cleanup, processor seam, and ZIP export are implemented. Annotation strokes keep coalesced pointer samples so fast drawings are not shortened, record their CSS stroke width for lossless re-rendering, and fade off the overlay four seconds after they are drawn without obscuring the page. The Chromium smoke test covers permission-modals, an existing microphone grant skipping its step, dock centering and stop placement, annotation tool tooltips and fade metadata, session keyboard shortcuts, discard confirmation, interactions, query-string stripping, denied-permission fallback, cancellation, and ZIP creation; actual OS display-picker behavior still needs manual browser testing.
- **Compiler core in progress:** the canonical compiler is the Rust crate `crates/highlite-compiler`. `compile_capture` remains pure: it defines the raw-capture and compiled-bundle contracts, pins marks and annotations, applies Scrawl's duration budget, aligns narration by clause, detects spoken cues, plans DOM-target crops, aligns timeline events to transcript and keyframes, collects docs refs, and emits a paste-ready handoff summary plus a Scrawl v1 export subset. The stdin/stdout CLI makes it usable from any language.
- **Agent bundle in progress:** the `bundle` subcommand owns the I/O around the pure compiler. It transcribes narration in the compile step (Parakeet via parakeet.cpp, Whisper via whisper.cpp, or a generic JSON command), shifts ASR timings by `audioOffsetMs`, crops each selected frame, burns every visible annotation into the cropped pixels at the recorded stroke width, renders `contact-sheet.png`, and writes `summary.md`, `scrawl.json`, `bundle.json`, `analysis.json`, `manifest.json`, and `frames/`. Parakeet is the English-first default when its model is configured; both local engines are optional subprocesses. The bundled Liberation Sans font (SIL OFL) is used for sheet labels.
- **Testing:** `fixtures/` holds the shared golden input/output used by the golden and CLI tests, `scripts/compiler-e2e.mjs` captures in Chromium then compiles the resulting SDK manifest through the Rust CLI, and `tests/bundle.rs` exercises the directory pipeline with rendered PNGs and fake transcribers. `scripts/parakeet-e2e.mjs` is an opt-in real-engine test: it needs `HIGHLITE_PARAKEET_BIN` and `HIGHLITE_PARAKEET_MODEL`, runs ffmpeg plus parakeet.cpp through `bundle`, and checks the transcript, timings, summary, frames, and contact sheet. The Scrawl export remains a browser subset until validated against Scrawl's own CLI.
- **Not implemented:** reference processor HTTP server, image redaction, smart auto-crop beyond DOM bounds, speech-cue frame capture when no frame exists, preview polish, and browser compatibility matrix.
